# 공기업 올인원 (Public Career All-in-One)

> **청년 취업 정보 격차 해소를 위한 공식 데이터 기반 AI 취업 의사결정 지원 플랫폼**
>
> 공식 채용공고만을 근거로 지원 자격과 가점을 분석합니다. 여러 기업의 준비 전략을 최적화하고, 공식 문서 기반 상담과 정정 공고 변경 감지까지 하나의 학습 플래너에서 제공합니다.

## 왜 만들었나: 해결하려는 사회적 문제

| 문제 | 현실 | 이 서비스의 접근 |
|---|---|---|
| 1. 청년 취업 정보 접근성 격차 | 공고를 해석하는 시간과 역량에 따라 준비의 질이 달라짐 | 공고 해석 결과를 누구나 같은 품질로 제공 |
| 2. 공공기관 채용정보의 파편화 | 기관별 사이트, 첨부 PDF·HWP·zip이 흩어져 있고, 가점표가 별첨 30쪽 뒤에 있기도 함 | 공식 문서를 구조화·색인하고 원문 페이지로 연결 |
| 3. 생성형 AI 환각으로 인한 의사결정 오류 | 그럴듯하지만 틀린 AI 답변 때문에 지원 기회를 놓칠 수 있음 | 점수는 코드로 계산하고, 상담은 검색된 원문 인용이 검증될 때만 답하며 아니면 보류 |
| 4. 불필요한 스펙 경쟁과 시간·비용 부담 | 가점에 반영되지 않는 자격증이나 범위 밖 과목에 자원을 씀 | "가산대상 목록에 없음", "범위 밖 과목", "추가 취득해도 +0점"을 명시하고, 제약 기반으로 최적화 |

## 핵심 가치
| 가치 | 구현 |
|---|---|
| **정확성** | 공식 원문 규칙만 사용합니다. 가점은 Python 규칙 엔진이 계산하고, 미검증 규칙은 계산을 차단합니다. |
| **신뢰성** | 모든 판단에 페이지와 인용문을 붙이고, 코드로 원문과 대조합니다. 모르는 것은 "확인 필요"로 표시하거나 답변을 보류합니다. |
| **접근성** | 공고, 첨부, 일정, 상담을 한 곳에서 제공합니다. 무료 공식 자료 링크와 ICS 내보내기도 지원합니다. |
| **개인 맞춤화** | 스펙 기반 자격·가점, 출제범위 공백 분석, 시간·예산 제약 최적화, 로드맵을 제공합니다. |

## 핵심 차별점: 공식 출처 검증과 분석 근거 제공
- **출처 검증 (코드 수준)**: 허용 도메인만 인정합니다. 위장 도메인(`korail.com.evil.io`), 블로그·카페, 사설·루프백 IP는 차단하고, 리다이렉트는 단계별로 재검증합니다.
- **근거 원문 대조**: 규칙 인용문 77건을 공식 PDF와 대조해 77건 모두 일치했습니다. 화면에서 각 항목 옆에 "공고문 p.3 ▾"를 펼치면 원문 인용, 페이지 전체, PDF를 볼 수 있습니다.
- **0점과 확인 불가를 구분**: "가산대상 목록에 없음", "공고에 기준 없음", "해석 필요"를 각각 분리해 표시합니다.

## 고도화 기능 3종 (이번 단계 추가)

### 1. 통합 취업 전략 최적화 (로드맵 → 통합 취업 전략 탭)
- **자격증 조합**: 비선형 0/1 배낭 문제입니다.
  - 가치는 Σ_기업 선호가중치 × (추가 가점 / 기업 일반자격증 가점 상한)으로 정의합니다.
  - 가점은 규칙 엔진이 집합 단위로 계산하므로 동일 종별, 영역별 인정 개수, 상한이 반영됩니다.
  - 후보 부분집합을 완전탐색해 정확한 최적해를 구합니다.
  - 테스트에서 단순 정렬(탐욕법)보다 나은 해를 찾는 사례를 확인했습니다.
- **주간 시간 배분**: `max Σ w_i·ln(1+h_i)  s.t. Σh_i = H`를 0.5시간 단위 한계효용 탐욕법으로 풉니다. 목적함수가 오목하고 분리 가능하므로 이 방법이 최적이며, 전수 탐색 결과와 같음을 테스트로 확인했습니다.
- **가중치 w**: 공식 출제 비중 × 기업 선호도 × 취약도 × 전략 계수로 정합니다.
- **제약조건**: 주간 시간, 예산(공식 응시료를 확보하지 못해 사용자 입력값만 반영), 보유 자격증 제외, 공식 근거가 검증된 가점만 사용, 목표 직렬이 다른 공고 기준 사용 금지.
- **전략 5종**: 균형형, 1순위 집중, 가점 확보, 필기 집중, 최소 비용 중에서 고를 수 있습니다.
- **로드맵 적용**: 계산 결과를 로드맵에 적용하는 버튼을 제공합니다.
- **분석 범위**: 공식 데이터가 있는 한국철도공사만 분석합니다. 한국전력공사와 서울교통공사는 "데이터 부족"으로 표시합니다.
- 화면에 표시되는 지표는 **합격 확률이 아닙니다.**

### 2. 공식 문서 기반 RAG 상담 (우측 하단 "채용 상담")
- **파이프라인**: 공식 PDF → 페이지별 텍스트 → 구조 보존 Chunking → 메타데이터 저장 → SQLite FTS5 + BM25 검색 → 공고 버전 필터 → IDF 가중 질의어 적중률로 충분성 판단 → 답변 또는 보류.
  - Chunking은 페이지 경계와 제목 기준 분할을 유지하고, 약 700자 단위에 2줄 overlap을 둡니다.
  - 한국어 형태소 분석기 대신 문자 2-gram 토큰을 사용합니다.
- **가점·중복 질문**: 규칙 엔진을 호출해 결정적으로 답합니다.
- **그 외 질문**: OpenAI `gpt-4o-mini`(또는 Claude)로 검색된 Chunk만 써서 답변을 생성하고, 세 단계 검증을 거칩니다.
  1. 인용문이 실제 Chunk에 있는지 코드로 확인합니다(실패하면 1회 재요청).
  2. 인용문에 질문하지 않은 다른 전형·직렬이 섞였는지 코드 범위 가드로 확인합니다.
  3. 인용문이 답을 직접 뒷받침하는지 LLM 판정기가 확인합니다.
  - 세 단계 중 하나라도 실패하면 답변을 보류합니다.
  - API 키가 없으면 AI 답변 없이 검색된 원문만 보여줍니다.
- **평가**: 실제 공식 문서로 22문항을 평가했습니다(LLM 연결 후).
  - LLM 근거 답변: 13/14
  - 답변 내용 정확: 12/13 (1건은 조건 누락)
  - 답변 보류 정확도: 5/5
  - 규칙 엔진 답변: 3/3
  - 인용 원문 검증: 17/17
  - 평균 약 3.3초
  - 자세한 내용은 [TEST_RESULTS](docs/TEST_RESULTS.md)를 참고하세요.

### 3. 정정 공고 변경 감지 (채용 → 변경 이력 탭, 상단 알림)
- **감지 단계**:
  1. SHA-256으로 파일이 같은지 비교합니다.
  2. 정규화 텍스트 해시를 비교해 메타데이터만 바뀐 경우는 "변경 없음"으로 처리합니다.
  3. difflib로 원문 Diff를 만듭니다.
  4. 구조화 규칙을 비교합니다(인원, 일정, 지원자격, 인정 자격증, 등급, 상한, 시험 과목).
  5. 중요도를 분류합니다.
  6. 규칙 엔진을 다시 실행해 나에게 미치는 영향을 분석합니다.
  7. 중복을 방지하며 웹 알림을 보냅니다.
- **버전 관리**: `recruitment_versions`에 원본 해시와 정규화 텍스트 해시를 버전별로 보존합니다.
- **동일 모집 건 판정**: 공고 번호와 정정 대상 명시로 판정합니다. 불명확하면 자동으로 연결하지 않습니다. 실제 상반기·하반기 공고는 "다른 모집 건"으로 판정됩니다.
- **실제 공고**: 수동 새로고침 버튼은 JOB-ALIO 공식 첨부파일을 다시 내려받아 비교합니다.
- **시연 데이터**: 변경 사례 시연에는 **시연용 가상 테스트 문서 A/B**(가상기관)만 사용하며, 실제 기관 데이터와 분리되어 있습니다.
- **정기 자동 확인**: 상시 실행 환경이 없어 **비활성**입니다. 화면에도 그렇게 표시합니다.

## 효과: 검증된 성과와 기대 효과
**검증된 성과 (2026-11-25, 실측)**
- 한국철도공사 2026 상반기 사무영업(IT) 공식 공고를 규칙화했고, 인용문 77/77이 원문과 일치합니다.
- 자동 테스트 47건이 통과했습니다(핵심 28건, 고도화 19건).
- RAG 평가 22문항(OpenAI 연결): 근거 답변 13/14, 내용 정확 12/13, 보류 정확도 5/5, 인용 검증 17/17.
- 최적화 정확성: 시간 배분은 전수 탐색과 같은 최적값이고, 자격증 조합은 탐욕법보다 높은 가치를 냅니다(테스트 사례).

**기대 효과 (목표, 측정하지 않음)**
- 정보 수집·관리 시간을 주 3시간에서 1시간으로 줄이는 것이 목표입니다(66.7% 절감, 연 약 104시간 예상).
- 가점 미반영 자격증 비용이 줄고, 기관을 확대하면 정보 격차가 완화될 것으로 기대합니다.

React 19, Vite, TypeScript, Tailwind CSS v4, Lucide, FastAPI, Python 3.12, SQLite(+FTS5), Pydantic v2, PyMuPDF, HTTPX, difflib, OpenAI API(gpt-4o-mini, 상담 답변·문서 추출), (대체) Anthropic Claude API, pytest

## 실행 방법 (Windows PowerShell)

```powershell
cd public-career-all-in-one; ./start.ps1
```

