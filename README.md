# 공기업 All-in-One (Public Career All-in-One)

> **청년 취업 정보 격차 해소를 위한 공식 데이터 기반 AI 취업 지원 플랫폼**
>
> 공식 채용공고만을 근거로 지원 자격과 가점을 분석하고, 개인별 취업 준비 로드맵으로 연결하는 웹 서비스

## 왜 만들었나: 해결하려는 사회적 문제

| 문제 | 현실 | 이 서비스의 접근 |
|---|---|---|
| 1. 청년 취업 정보 접근성 격차 | 공고문을 찾고 해석하는 능력과 시간이 있어야 제대로 준비할 수 있음 | 공고 해석 결과를 누구나 같은 품질로 볼 수 있도록 제공 |
| 2. 공공기관 채용정보의 파편화 | 기관마다 사이트와 첨부파일(PDF·HWP·zip) 형식이 다르고, 가점표가 별첨 30쪽 뒤에 있기도 함 | 공식 공고와 첨부파일을 한 곳에서 구조화하고 원문 페이지로 연결 |
| 3. 생성형 AI 환각으로 인한 의사결정 오류 | AI가 그럴듯하지만 틀린 가점·자격 정보를 말하면 지원 기회를 놓칠 수 있음 | AI가 점수를 만들지 않음. 공식 원문에 있는 규칙만 코드로 계산하고 근거를 표시 |
| 4. 불필요한 스펙 경쟁과 시간·비용 부담 | 가점에 반영되지 않는 자격증이나 출제범위 밖 과목에 시간과 비용을 씀 | "가산대상 목록에 없음"과 "출제범위 밖 과목"을 명시해 우선순위 판단을 도움 |

개발자 본인이 공기업 전산직을 준비하며 겪은 불편에서 출발했습니다. 기업마다 다른 지원 자격, 가점 기준, 필기 과목을 반복해서 확인해야 했고, 생성형 AI의 답변을 그대로 믿기 어려웠습니다.

## 핵심 가치

| 가치 | 구현 방식 |
|---|---|
| **정확성** | 공식 공고 원문에 있는 규칙만 사용합니다. 가점은 AI가 아닌 Python 규칙 엔진이 계산합니다. 확인되지 않은 규칙으로는 계산하지 않습니다. |
| **신뢰성** | 모든 판단에 공고문 페이지와 인용문을 붙이고, 그 인용문이 실제 PDF에 있는지 코드로 검증합니다. 모르는 것은 "확인 필요" 또는 "공고에 기준 없음"으로 표시합니다. |
| **접근성** | 흩어진 공고, 첨부파일, 일정을 한 화면에 모읍니다. 무료 공식 학습 자료 링크와 ICS 캘린더 내보내기를 제공합니다. |
| **개인 맞춤화** | 내 스펙과 준비 상태를 기준으로 지원 자격, 가점, 출제범위 대비 공백, 8주 로드맵을 산출합니다. |

## 핵심 차별점: 공식 출처 검증과 분석 근거 제공

1. **출처 검증을 코드로 수행** ([source_verifier.py](backend/app/services/source_verifier.py))
   - 기업별 허용 도메인만 인정합니다(정확 일치 또는 하위 도메인).
   - `korail.com.evil.io`처럼 기업명이 들어간 위장 도메인은 거부합니다.
   - 블로그·카페·SNS를 차단합니다.
   - 리다이렉트를 단계마다 다시 검증합니다.
   - SSRF를 막기 위해 사설·루프백·링크로컬 IP와 IP 직접 접근을 차단합니다.
   - 다운로드 파일은 30MB로 제한합니다.
2. **근거 원문 자동 대조** ([evidence_validator.py](backend/app/services/evidence_validator.py))
   - 규칙 파일의 모든 인용문(현재 77건)을 서버 시작 시 공식 PDF 원문과 대조합니다.
   - 불일치하면 해당 공고를 "부분 검증"으로 표시하고 그 규칙은 판단을 보류합니다.
3. **화면에서 근거 바로 확인**
   - 판단·가점·일정마다 `공고문 p.3` 같은 링크가 있습니다.
   - 누르면 해당 페이지 원문을 하이라이트해서 보여줍니다.
   - JOB-ALIO 원본 첨부파일 링크도 함께 제공합니다.
4. **확인 불가와 0점을 구분**
   - 가산대상 목록에 없는 자격증(예: SQLD)은 "가산대상 목록에 없음"으로 표시하고 0점으로 처리하지 않습니다.
   - 공고에 없는 어학 기준은 "공고에 기준 없음"으로 표시합니다.
   - 공고 해석이 필요한 항목은 "해석 필요"로 분리해 두 가지 합계를 보여줍니다.

## 사회적 효과: 검증된 성과와 기대 효과를 구분해 적습니다

### 현재까지 검증된 성과 (2026-11-25 기준, 실측)
- 한국철도공사 2026년 상반기 신입사원 공고([2026-02호]) 중 **사무영업(IT)** 직렬 1건을 분석 규칙으로 구조화했습니다.
- 규칙 근거 인용문 **77건 전부** 공식 PDF 원문과 일치함을 코드로 확인했습니다(`/api/health`에서 확인 가능).
- 자격증 가점표([참고4])는 PDF 원본 이미지로 사람이 육안 대조했습니다.
- 자동 테스트 **28건이 통과**했습니다. 공식 출처 검증 12건, 근거 검증 2건, 지원 자격 4건, 가점 계산 10건입니다([TEST_RESULTS](docs/TEST_RESULTS.md)).

### 기대 효과 (목표치, 실사용으로 측정하지 않음)
- 공고 정보 수집·관리 시간: 주 3시간에서 주 1시간으로 줄이는 것이 목표입니다(66.7% 절감, 연 약 104시간 예상).
- 가점 미반영 자격증 취득이나 출제범위 밖 과목 학습 같은 불필요한 준비 비용이 줄어들 것으로 기대합니다.
- 대상 기관을 늘리면 정보 접근성 격차가 완화될 것으로 기대합니다.

> 위 기대 효과는 사용자 실측 결과가 아닙니다. 실제 효과는 사용자 테스트로 측정해야 합니다.

| 기능 | 상태 |
|---|---|

| 내 스펙 관리(자격증·어학·경험·NCS·전공·인턴·자가 확인) + SQLite 저장 | 구현 |
| 공식 채용공고 목록·필터, 출처 검증, URL 수집, PDF 업로드(해시 중복 방지) | 구현 |
| PDF 페이지별 텍스트 추출 + 키워드 기반 근거 후보 탐색 | 구현 |
| 지원 자격 판단(충족/미충족/확인 필요/해당 없음/공고에 기준 없음) | 구현 |
| 필기 가점 계산(등급별 점수, 동일 종별 최고 1개, 영역별 인정 개수, 최대 3개·12점, 총 20점, 유효기간, 기준일) | 구현 |
| 가점 시뮬레이터 | 구현 |
| NCS·전공 출제범위 × 내 준비 상태 분석, 출제범위 밖 과목 안내 | 구현 |
| 8주 맞춤 로드맵 + 체크리스트 + 진척도 | 구현(규칙 기반) |
| 채용 캘린더 + ICS 다운로드 | 구현 |
| 추천 학습 자료 + 서점 검색 링크 | 구현(가격 비교는 미구현, 가격을 표시하지 않음) |
| AI 구조화 추출(Claude API, Pydantic 검증, 인용문 재검증) | 코드 구현, **API 키가 없어 실행 검증 안 함** |
| 경쟁력(안정권/적정권/도전권) | 공식 합격선 데이터가 없어 **"판단 불가"로 표시**. 공고 기준 선발 배수만 제공 |
| 알림 설정 | 설정 저장만 구현. 스케줄러와 이메일 발송은 **구현 예정** |
| 한국전력공사·서울교통공사 | 기업 등록과 허용 도메인만 있고 **공식 공고 미등록(분석 불가)** |
| HWP/HWPX, OCR, Google Calendar OAuth, 공고 자동 수집 | 구현 예정 |

## 실제 공식 공고로 검증한 범위
- 기관 및 직렬: **한국철도공사 / 사무영업(IT) / 공개경쟁 신입 / 수도권 10명**
- 공고: 2026년 상반기 한국철도공사 신입사원 채용 공고 (JOB-ALIO `idx=297210`, 2026-02-25 게시, **접수 마감된 과거 공고**)
- 최신 공고: 2026년 하반기 공고(`idx=303642`, 2026-08-07)를 확인했으나 공개경쟁은 토목·전기통신만 모집해 **IT 직렬이 없었습니다**. 앱에서도 이 공고는 "IT 모집 없음"으로 표시합니다.

## 기술 스택
React 19 + Vite + TypeScript, Tailwind CSS v4, Lucide, React Router, FastAPI, Python 3.12, SQLite(sqlite3), Pydantic v2, PyMuPDF, HTTPX, (선택) Anthropic Claude API, pytest

## 실행 방법 (Windows PowerShell)

```powershell
cd public-career-all-in-one
./start.ps1
```

브라우저에서 http://127.0.0.1:8000 을 엽니다. 이 주소는 로컬 전용이며 공개 URL이 아닙니다.

개발 모드로 실행하려면 다음 두 명령을 각각 실행합니다.

```powershell
backend\.venv\Scripts\python.exe -m uvicorn app.main:app --app-dir backend --reload --port 8000
```

```powershell
cd frontend; npm run dev
```

테스트 실행:

```powershell
cd backend; .venv\Scripts\python.exe -m pytest -q
```

(선택) AI 추출을 쓰려면 `ANTHROPIC_API_KEY` 환경변수를 설정한 뒤 서버를 시작합니다. 키는 백엔드에서만 사용합니다.

## 개인정보
- 저장소에는 실명, 학교명, 연락처를 넣지 않았습니다. `data/demo/demo_profile.json`은 가상 데모 프로필입니다.
- 로그인 기능이 없으므로 개인정보를 입력한 상태로 공개 배포하지 않습니다.
