# 개인정보 보호

- **저장 위치**: 사용자 스펙은 실행 중인 서버의 로컬 SQLite(`backend/app.db`)에만 저장합니다. 이 파일은 `.gitignore`와 제출 ZIP에서 제외됩니다.
- **인증 부재**: 로그인 기능이 없으므로 공개 서버에 배포하지 않습니다. 공개 배포 시에는 인증을 도입한 뒤 사용자별로 데이터를 분리해야 합니다.
- **상담 대화**: 서버 DB에 저장하지 않고 브라우저 `sessionStorage`(탭 세션)에만 보관합니다. 상담창의 초기화 버튼으로 삭제할 수 있습니다.
- **AI API 전송 최소화**:
  - RAG 상담에는 닉네임, 학력, 지역 등을 넘기지 않고 계산에 필요한 필드(자격증, 출생연도, 병역, 자가 확인, 인턴)만 서버 안에서 사용합니다.
  - LLM에는 공고 Chunk와 질문만 전달합니다.
- **알림 이메일**: 입력값만 저장하며 발송 기능은 미구현입니다. 수신 동의 체크가 있어야 발송 대상이 되도록 설계했습니다.
- **익명 준비생 비교**: 실제 이용자 통계가 없어 제공하지 않으며, 임의의 통계를 만들지 않습니다.
- **공개 저장소**: 가상 데모 프로필만 포함하고, 실명·학교명·연락처는 넣지 않았습니다.
- **API Key**: `.env`나 환경변수로 관리하며 프론트엔드에 노출하지 않습니다.
