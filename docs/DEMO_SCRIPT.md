# 시연 영상 대본 (약 3분)

준비:
1. `backend/app.db`를 지웁니다.
2. `./start.ps1`을 실행합니다.
3. 로드맵 탭에서 "8주 로드맵 만들기"를 한 번 눌러 둡니다.

| 시간 | 화면 | 진행 |
|---|---|---|
| 0:00~0:20 | 홈 | 공식 공고만 근거로 쓰는 취업 의사결정 지원 서비스라고 소개합니다. 4가지 사회적 문제는 말로만 짧게 언급합니다. 왼쪽 목표 기업과 준비 현황, 오른쪽 이번 주 목표, 오늘 할 일, 캘린더를 보여줍니다. |
| 0:20~0:55 | 내 스펙 → 분석 | 지원 자격 항목 옆 "공고문 p.2 ▾"를 펼쳐 원문 인용과 페이지 전체를 보여줍니다. 가점 결과를 짚습니다: 한국사 2.5 인정, SQLD는 목록에 없음, 정보처리기사는 해석 필요. 서류는 적부 판정이라 점수를 산출하지 않는다고 설명합니다. |
| 0:55~1:10 | 내 스펙 → 가점 시뮬레이터 | 컴활 1급을 선택해 +0점이 되는 것을 보여주고, 불필요한 스펙을 피하는 판단이라고 설명합니다. |
| 1:10~1:45 | 로드맵 → 통합 취업 전략 | 주간 시간 슬라이더와 전략(균형형 → 가점 확보)을 바꿔 다시 계산합니다. 시간 배분과 추천 자격증 조합을 보여줍니다. 완전탐색과 단순 정렬을 비교한 수치, 한전·서울교통 "데이터 부족" 표시, "합격 확률 아님" 문구를 짚습니다. "로드맵에 적용"을 누릅니다. |
| 1:45~2:20 | 우측 하단 채용 상담 | "정보처리기사랑 SQLD 가점이 중복 인정돼?"는 규칙 엔진 답변과 근거 펼침으로 답합니다. "NCS 출제 대행사가 공개되어 있어?"는 답변을 보류합니다. AI 키가 없으면 가짜 AI 답변을 만들지 않는다고 설명합니다. |
| 2:20~2:50 | 채용 → 변경 이력 | 실제 공고의 버전 v1(해시)과 "공식 사이트 다시 확인"을 보여줍니다. **시연용 가상 문서**의 정정 비교 표(마감일·인원·자격증·과목), 원문 Diff 색상, 나에게 미치는 영향을 보여주고, 상단 종 아이콘 알림을 엽니다. |
| 2:50~3:00 | - | 검증된 성과(근거 77/77, 테스트 47건, RAG Recall@3 14/15, 보류 5/5)와 기대 효과(목표)를 구분해 말하고 마무리합니다. |
