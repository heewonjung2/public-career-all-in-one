## 사용하지 않은 것
- 블로그, 카페, 커뮤니티, 개인 후기, 다른 AI의 답변, LLM 사전 지식
- 자격증 응시료와 시험 일정: 시행기관(Q-Net 등) 공식 자료를 수집하지 않아 표시하지 않음
- 과거 합격선과 경쟁률: 공식 자료를 확보하지 못해 "판단 불가"로 표시
- 한국전력공사, 서울교통공사: 공식 공고를 등록하지 않아 "데이터 부족"으로 표시
- 준비 시간 기본값(기사 120시간 등): 일반 추정치이며 화면에 "일반 추정치"로 표시하고 사용자가 수정할 수 있음
