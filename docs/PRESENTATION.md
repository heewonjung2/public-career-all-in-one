# 발표자료: 공기업 All-in-One

> 슬라이드 1장 = 아래 `---` 구분 1개. 3분 발표 기준입니다.

---
## 1. 공기업 All-in-One
**청년 취업 정보 격차 해소를 위한 공식 데이터 기반 AI 취업 지원 플랫폼**

공식 채용공고만을 근거로 지원 자격과 가점을 분석하고, 맞춤형 로드맵으로 연결합니다.

---
## 2. 문제: 정보는 많지만 믿고 쓸 정보는 찾기 어렵다
1. 청년 취업 **정보 접근성 격차**
2. 공공기관 채용정보의 **파편화**: 가점표가 별첨 PDF 22~24쪽에 있음
3. 생성형 AI **환각**으로 인한 잘못된 의사결정
4. **불필요한 스펙 경쟁**과 시간·비용 부담

개발자 본인 경험: 공기업 전산직을 준비하며 기업별 자격·가점·과목을 매주 약 3시간씩 수동으로 확인했습니다.

---
## 3. 핵심 가치
| 정확성 | 신뢰성 | 접근성 | 개인 맞춤화 |
|---|---|---|---|
| 공식 원문 규칙만 사용, 코드로 계산 | 모든 결과에 페이지·인용문, "확인 필요" 표시 | 흩어진 공고를 한 화면에 | 내 스펙 기준 자격·가점·로드맵 |

---
## 4. 핵심 차별점: 공식 출처 검증 + 분석 근거
- 허용 도메인만 인정합니다. `korail.com.evil.io`, 블로그, 내부망 주소는 차단합니다.
- 근거 인용문 **77건을 공식 PDF 원문과 자동 대조**했고 77건 모두 일치했습니다.
- 클릭하면 원문 페이지를 하이라이트해서 보여줍니다.
- **AI는 점수를 만들지 않습니다.** 검증된 규칙을 Python 엔진이 계산합니다.

---
## 5. 시연 결과 (실제 공고: 코레일 2026 상반기 사무영업 IT)
- 지원 자격: 연령·학력·병역 충족. 기타사항은 본인 확인 후 충족 처리
- 서류전형: 적부 판정이라 **"예상 서류 점수 산출 대상 아님"**으로 정직하게 표시
- 필기 가점: **확정 2.5점 / 해석 포함 6.5점**
  - SQLD는 가산대상 목록에 없음
  - 컴활 2급은 공통직무 1개 제한으로 미반영
- 출제범위: 컴퓨터일반 6과목. 준비 중인 인공지능·알고리즘은 **범위 밖**

---
## 6. 불필요한 스펙 경쟁을 줄이는 판단
- 시뮬레이터 결과, 컴활 1급을 추가로 취득해도 **+0점**입니다. 공통직무 영역이 이미 채워져 있기 때문입니다.
- 정보보안기사를 취득하면 직렬별 영역이 늘어나 +4.0점입니다(해석 필요 항목).
- 로드맵은 출제범위 안에서 취약한 데이터통신·전자계산기와 응용수리를 우선합니다.

---
## 7. 아키텍처와 기술
React + TypeScript + Tailwind → FastAPI → SQLite + 공식 PDF 보관본(PyMuPDF)
- 출처 검증기, 근거 검증기, 자격 엔진, 가점 엔진, 로드맵 생성기
- (선택) Claude API 구조화 추출: 스키마 검증과 인용문 재검증 후 "검증 필요" 상태로만 저장

---
## 8. 효과: 검증된 것과 기대하는 것
**검증된 성과(실측)**
- 공식 공고 1건 규칙화, 인용문 77/77 일치
- 자동 테스트 28건 통과(출처 차단, 가점 중복·상한, 유효기간 등)

**기대 효과(목표, 미측정)**
- 주 3시간 → 1시간 (66.7% 절감, 연 약 104시간)
- 가점 미반영 자격증 비용 절감, 정보 격차 완화

## 9. 한계와 다음 단계

## 10. 고도화 ① 통합 취업 전략 최적화
- 자격증 조합: 비선형 0/1 배낭 → **완전탐색으로 정확한 최적해**. 단순 정렬은 "같은 영역 1개 인정" 규칙을 놓칩니다.
- 시간 배분: `max Σ w·ln(1+h)` → 한계효용 탐욕법(최적, 전수 탐색으로 검증)
- 제약: 주간 시간, 예산, 보유 자격증, 공식 근거가 있는 가점만
- 전략 5종, 로드맵 바로 적용, "합격 확률 아님" 명시

---
## 11. 고도화 ② 공식 문서 RAG 상담
- 206개 Chunk(SQLite FTS5·BM25), 공고 버전 필터, 근거가 부족하면 **답변 보류**
- 가점 질문은 규칙 엔진이 계산하고, 인용문은 코드로 원문과 대조
- 실측: Recall@3 14/15, 보류 정확도 5/5, 인용 검증 17/17, 약 6ms

---
## 12. 고도화 ③ 정정 공고 변경 감지
- 파일 해시 → 정규화 텍스트 해시(메타데이터만 바뀐 경우 오탐 방지) → 원문 Diff → 규칙 Diff → 중요도
- 내 가점·자격·일정·로드맵에 미치는 영향을 재계산하고, 중복 없이 알림
- 실제 상·하반기 공고는 "다른 모집 건"으로 판정해 잘못된 연결을 방지
- 시연은 **가상 테스트 문서**로만 진행합니다(실제 정정 공고 아님).
