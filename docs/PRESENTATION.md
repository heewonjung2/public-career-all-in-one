## 1. 한 줄 소개 (15초)
**공기업 올인원: 공식 채용공고만 근거로 내 가점과 공부 계획을 알려주는 취업 준비 플랫폼**

목표 기업을 고르면 공식 공고를 분석해 지원 자격·가점·필기 과목·8주 로드맵까지 한 화면에서 이어 줍니다.

---
## 2. 문제 (30초)
1. **정보 파편화**: 가점표가 공고 별첨 PDF 뒤쪽에 있고, 기관마다 형식이 다릅니다.
2. **정보 접근성 격차**: 읽고 해석할 시간·능력에 따라 준비 수준이 갈립니다.
3. **생성형 AI 환각**: 그럴듯하지만 틀린 답으로 잘못된 결정을 합니다.
4. **불필요한 스펙 경쟁**: 가점에 반영되지 않는 자격증에 시간과 돈을 씁니다.

개발자 경험: 기업별 자격·가점·과목 확인에 매주 약 3시간이 들었습니다.

---
## 3. 해결 방식 = 핵심 차별점 (30초)
- **공식 출처만 사용**: JOB-ALIO·ALIO·클린아이·기관 공식 도메인만 인정, 블로그·위장 주소·내부망 차단
- **모든 결과에 근거**: 문서·페이지·인용문 표시, 공식 PDF 원문과 자동 대조
  - 2026 상반기 공고 **112/112**, 2026 하반기 **4/4**, 2027 사전예고 **101/101** 일치
- **AI는 점수를 만들지 않음**: 검증된 규칙을 가점 엔진(코드)이 계산, 확인 안 되면 "확인 필요"

---
## 4. 시연 흐름 (60초)
1. **목표 기업 선택**: 공공기관 **1,399곳**(ALIO 중앙 355 + 클린아이 지방 1,044) 중 약칭(한수원·코레일·금감원)으로 검색·저장
2. **공고 → 로드맵**: 코레일 2026 상반기 공고 → 사무영업(IT) → 필기 과목과 근거(참고자료 p.35) → 8주 로드맵
3. **가점 분석**: 정보처리기사 4.0 + 한국사 1급 2.5 = **6.5점**
   - SQLD: 가산대상 목록에 없음(0점)
   - 컴활 2급: 같은 영역 1개만 인정 → 제외
4. **취뽀봇**: "SQLD 몇 점?" → 기업 되묻기 → 같은 기준으로 후속 질문 답변, "기사 뭐 더 따면 좋아?" → 시뮬레이터 실제 추가 점수(+4.0점 후보)

---
## 5. 스펙 경쟁을 줄이는 판단 (15초)
- 따도 점수가 안 오르는 자격증은 **+0점과 그 이유**를 보여 줍니다.
- 공식 기준이 없는 기관은 다른 기관 점수를 섞지 않고 **"가점 분석 준비 중"**으로 표시합니다.
- 필기 과목을 원문에서 확인하지 못하면 **"필기 과목 확인 필요" + 공식 공고 보기**로 안내합니다.

---
## 6. 기술 (15초)
React + TypeScript + Tailwind → FastAPI → SQLite + 공식 PDF 보관본(PyMuPDF)
- 출처 검증기, 근거 검증기, 자격·가점 엔진(완전탐색 최적 조합), 로드맵 생성기
- OpenAI: 공식 도메인 한정 공고 검색, 공식 문서 기반 상담(인용 원문 대조 후 답변, 부족하면 보류)
- 자동 테스트 **103건 통과**, Render 배포

---
## 7. 효과와 한계 (15초)
**검증된 성과(실측)**
- 공식 근거 대조 100% 일치(위 3개 문서), 테스트 103건, 배포본에서 주요 흐름 확인
- RAG 상담 평가: 근거 답변 13/14, 보류 정확도 5/5, 인용 검증 17/17

**기대 효과(목표, 미측정)**
- 정보 확인 시간 주 3시간 → 1시간(66.7% 절감)

**한계**
- 가점까지 검증된 기관은 코레일뿐. 다른 기관은 공고 검색·분석·로드맵까지 지원
- 지방 출자·출연기관 892곳 중 877곳 반영(15곳 대조 필요)
