# 구현 상태 (2026-11-25, 통합 개발 지시서 v3.0 기준)

자동 테스트: **86건 통과** (`backend/tests`). 테스트 통과가 공식 채용 기준의 완전한 검증을 뜻하지는 않습니다.

## 1. 구현 및 검증 완료
| 기능 | 검증 내용 |
|---|---|
| 공식 출처 검증 + SSRF 차단 | 허용 도메인(JOB-ALIO·ALIO·클린아이·기관 도메인), 위장 도메인·블로그·내부 IP 차단 테스트 |
| 근거 원문 대조 | 2026H1 규칙 112/112, 2026H2 4/4, 2027 사전예고 101/101 인용문이 공식 PDF와 일치 |
| 가점 엔진 v2 (`bonus.py`) | pools·그룹·전체 개수·상한·동일 종별·복수 그룹 배정을 완전탐색으로 최적화. 가상 규칙 16건 + 코레일 실규칙 테스트 |
| 직렬 계층 상속 | 코레일 IT = 사무영업 세부구분(공고문 p.1 인원표, 참고자료 p.4) → 사무영업 직렬별 목록 적용 |
| 코레일 2026 상반기 사무영업(IT) 가점 | 데모 프로필: 정보처리기사 4.0 + 한국사 1급 2.5 = **6.5점**. 컴활 2급은 공통직무 1개 제한, SQLD는 목록 외 |
| 2027 상반기 채용방식 변경 사전예고 | 서류 점수제(어학 60 + 자격증 원점수×2, 사무영업), 환산표(표 격자 추출 + 이미지 육안 대조), 유효기간 2년·사전등록 인정 |
| 2027 서류 점수 | 자격증 13점 확정. 어학은 응시일 입력 시 반영(조건부 73점 → 입력 후 73점) — 테스트로 확인 |
| 공고 버전 공통화 | 분석·시뮬레이터·통합 전략·RAG·로드맵이 같은 `active_recruitment_id` 사용(테스트) |
| 어학 데이터 구조·마이그레이션 | `exam_date`·`original_expiry_date`·사전등록 필드. 의미가 불명확한 구 날짜는 변환하지 않고 `legacy_date`로 보존 |
| RAG 상담 (OpenAI gpt-4o-mini) | 2026 문서 22문항: 근거 답변 13/14, 보류 5/5, 인용 17/17(2027 추가 전) |
| 전국 공공기관 공고 검색 | OpenAI `gpt-5-mini` web_search(JOB-ALIO·ALIO·클린아이 도메인 한정) → 상세 페이지를 코드로 다시 받아 기관명·제목 확인. 실제 검색: 한국공항공사 6건 확인 |
| 요청 기반 공고 분석 | JOB-ALIO 첨부 PDF 확보 → AI 구조화 → 인용 대조. 실제 사례: 코레일 2026 하반기 공고 23건 추출·13건 원문 일치 |
| 홈 대시보드 | 시안 기준 68:32, 라벤더·화이트, 병아리 환영 영역, 분포 그래프(시연용 가상 데이터 표시) |
| 시연용 가상 분포 | 고정 시드 1,000명, 실제 엔진으로 점수 계산, 사용자 점수 변경 시 백분위 재계산 |
| AI 호출 사용량 제한 | IP당·전체 시간당 한도(429) 테스트 |

## 2. 구현 완료, 추가 검증 필요
- 2027 문서에 대한 RAG 답변 품질 재평가
- 정정 공고 "공식 사이트 다시 확인" 실제 재다운로드(기능 구현, 자동 테스트 미포함)
- 검색으로 찾은 신규 기관 공고의 AI 추출 규칙 → 가점 엔진 연결(현재는 '검증 필요'로만 표시, 계산 미반영)
- 모바일 화면(홈은 확인, 나머지 페이지는 부분 확인)

## 3. 부분 구현
- 기업 검색 결과 필터(기관 유형·지역·직렬·연도)는 미구현 — 기관명 검색만
- 신규 기관 모집 직렬 추출: 프롬프트로 인원표 직렬 추출을 요청하나 정확도 미검증
- 어학 만료 알림: 분석 화면 안내만, 90/30/7/1일 알림·캘린더 표시는 미구현
- 통합 전략의 복수 기업 비교: 공식 규칙이 검증된 기업만 계산(현재 코레일), 나머지는 데이터 부족 표시

## 4. 시연용 기능
- 가상 취업준비생 분포(실제 이용자 통계 아님)
- 정정 공고 변경 감지 시연(가상기관 문서 A/B)

## 5. 미구현
- 신규 사용자 초기 설정 마법사, 직무 계열별 가상 프로필 6종
- 개인 프로필의 브라우저 로컬 저장(현재 서버 SQLite, 공개 시연 서버는 공유 데이터임을 안내)
- HWP/HWPX/이미지 공고 분석(OCR), 벡터 검색, 문제집 가격 비교, 이메일·Google Calendar 연동, 정기 스케줄러
- 공식 합격선·경쟁률 수집, 통계 참여 동의 관리
- 상태 코드(ELIGIBLE 등) 분리: 백엔드 상태 문구를 그대로 사용(프론트 색상 매핑에 새 문구 추가로 대응)

## 6. 외부 API·인증
- OpenAI API: 사용 중(`.env`/배포 환경변수). 웹 검색은 `gpt-5-mini`, 추출·상담은 `gpt-4o-mini`
- 공공데이터포털 API: 인증키 없음 → 미연동(Provider 구조만 문서화)
